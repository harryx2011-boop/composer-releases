# Composer releases

Installers for Composer, an intelligent and conversational voice model that runs on your own machine.

Download the latest `Composer-<version>-Setup.exe` from the Releases tab. Windows 11, 64-bit. Ollama must be installed separately. An NVIDIA GPU is recommended; it runs without one.

`latest.yml` and the `.blockmap` beside each installer are what an installed copy polls for updates.
